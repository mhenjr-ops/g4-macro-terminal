Data provenance · Spot rates are ECB daily reference rates via the Frankfurter API, published each TARGET business day around 16:00 CET. RSI(14) is Wilder's smoothing on daily closes; SMA(200) is a simple mean of the last 200 published closes. The dollar index is reconstructed from the six ICE component rates using the published weights — it tracks DXY closely but is not the exchange-traded index. There is no intraday data here: every reading is an end-of-day close, so this is a daily planning tool, not an execution screen.
